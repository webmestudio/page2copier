Two ways to save a page Text mode drives the browser print engine, so the PDF keeps selectable text and working links. Snapshot mode captures the painted pixels instead, which is what you want for canvas, maps and charts. Press Alt+Shift+P to save the tab you are on, or right click anywhere for the rest.
